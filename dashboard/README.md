# Dashboard

**Dark Neon Analytics Dashboard for AI Strategy Simulator**

## Quick Start

```bash
streamlit run dashboard/app.py
```

Open your browser to **http://localhost:8501**

## Features

### 🎨 Dark Neon Analytics Theme
- Deep navy/black background (#0e1117)
- Purple/magenta/pink neon accents
- Smooth gradients and glowing effects
- Research-grade clarity

### 📊 Visualizations

**Market View:**
- Baseline market canvas (before simulation)
- Active market landscape (after simulation)
- Firm nodes sized by market share
- Color-coded strategies

**Time-Series Charts:**
- Prices over time (all firms + marginal cost)
- Cumulative profits
- Market share evolution (stacked area)
- Innovation stock accumulation
- HHI with economic regime overlay
- Price dispersion (detects price wars)

**Strategic Analysis:**
- Final market shares (bar chart)
- Profit distribution
- Innovation vs market share scatter

### 🤖 Auto-Generated Summary

The dashboard automatically analyzes tournament results and generates:
- Market structure classification (monopolistic/competitive/etc.)
- Winner identification with strategy
- Firm rankings with performance metrics
- Price war detection
- Innovation leader analysis
- Real-world market parallels

### ⚙️ Controls

**Sidebar:**
- Version selector (V1/V2)
- Experiment selector
- Show/hide market economics
- Chart toggles

**Main Panel:**
- Run Simulation button
- Interactive chart selection
- Data export (CSV download)

## Data Source

Reads tournament results CSV generated by the experiment pipeline.

Generated by (recommended):

```bash
python run_experiment.py --timesteps 500000 --seed 123
```

This creates a new run folder under:

```
results/run_YYYYMMDD_HHMMSS/tournament_results.csv
```

The dashboard automatically loads the latest `results/run_*/tournament_results.csv` if present, and falls back to legacy paths if not.

## Key Metrics Explained

**HHI (Herfindahl-Hirschman Index):**
- < 0.15: Competitive
- 0.15-0.25: Moderate concentration
- 0.25-0.50: High concentration
- > 0.50: Monopolistic

**Price War Detection:**
- Price std dev > $5 indicates active price competition

**Market Structure:**
- Auto-classified based on HHI and share distribution

**Strategy Classification:**
- Innovation Leader: High R&D investment
- Price Warrior: Low margins, aggressive pricing
- Generic Follower: Low innovation, moderate prices
